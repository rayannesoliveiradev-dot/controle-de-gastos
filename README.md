# Controle de Gastos

Projeto desenvolvido em Python para praticar programação e organização de dados utilizando banco de dados.

# Sobre o projeto

O Controle de Gastos é um projeto pessoal criado com o objetivo de praticar conceitos de Python e persistência de dados.

# Tecnologias utilizadas

- **Python** — lógica e desenvolvimento do programa.
- **SQLite** — banco de dados para armazenamento de informações.
- **Git e GitHub** — controle de versões e armazenamento do código.

# Arquivos principais

- `Planilha.py` — código principal do projeto.
- `Planilha.db` — arquivo do banco de dados SQLite.

# Objetivos de aprendizagem

- Praticar programação com Python.
- Trabalhar com armazenamento de dados.
- Aprender a versionar projetos usando Git.
- Organizar projetos para um portfólio de desenvolvimento.

# Próximas melhorias

- Aprimorar a validação dos dados.
- Melhorar a organização do código.
- Adicionar relatórios e consultas.
- Desenvolver novas funcionalidades para o controle de gastos.

**Projeto pessoal desenvolvido para fins de estudo e aprendizado.**
